# 听云苑 · 体素古建漫游

本次全新设计的中国古典体素建筑群。原生 JavaScript + Three.js + Vite，无需后端。场景和界面均在本次项目中编写。

## 直接观看

双击交付的 **听云苑-离线版.html** 即可观看。全部脚本、样式和匾额绘制都在文件内，不依赖 CDN、在线字体或外部图片，断网也能运行。

需要支持 WebGL 2 的现代浏览器。页面打开后直接显示院落全貌。

## 安装与启动

建议使用 Node.js 22.12 或以上版本；本次使用 Node.js 24.19.0 验证。

在项目目录执行：

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173/ 。项目将端口固定为 5173；若已被占用，可以运行 `npm run dev -- --port 5174`。

生产构建与预览：

```sh
npm run build
npm run preview
```

生产预览地址为 http://127.0.0.1:4173/ 。`dist/index.html` 适用于静态网站服务；`dist/听云苑-离线版.html` 是可以直接双击打开的单文件版本。

## 场景与交互

- 中轴从前向后串联承风门、庭院和听云殿；听云殿为体量最大的重檐主殿。
- 观澜阁、栖霞阁对称分列两侧，钟楼、鼓楼位于前庭两侧，共六座建筑。
- 主殿采用金色庑殿顶，配殿与山门采用青瓦歇山顶，钟鼓楼上部采用攒尖顶。屋面逐块抬升，四角另设上翘飞檐。
- 朱红立柱、抽象体素斗拱、石台阶与栏杆，配合木格窗、门钉、匾额、灯笼和石狮。
- 石铺庭院、明确的中轴与横向支路、双水池、松树、围墙和分层石台。
- 晨光与暮色使用不同的日照高度、色温、环境光与阴影。

鼠标左键拖动旋转，滚轮缩放，右键拖动平移。触屏支持单指旋转、双指缩放及平移。

底部可选择全景、中轴、环游，切换晨暮或复位。快捷键 `R` 复位，空格启停环游；按钮获得键盘焦点时保留按钮本身的键盘行为。

## 性能与实现

全场景 13,175 个块，使用 `InstancedMesh` 按材质合批。所有块共享一个立方体几何体，避免逐块创建网格。只有六块匾额使用单独平面和本地 Canvas 贴图。

阴影分辨率为 2048，渲染像素比最高 1.5。没有逐体素动画或后处理，环游只更新相机。正交相机根据场景包围盒和页面比例自动取景；不使用会冲淡手机画面的距离雾。

运行与构建已实际验证，详细结果见 **验证记录.md**。帧率来自本次设备和浏览器的实时计数，不能推定为所有设备上的固定帧率。
